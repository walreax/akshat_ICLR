Concept Fidelity Score

How one image gets a fidelity score

Five stages turn a single prompt into a scalar. The per-image path (blue) runs once per test image; Stage 3 additionally depends on a latent bank built once from the 600-prompt calibration set (violet) — that's the fix for argmax collapsing onto the same generic latent for every concept.
