METRIC SPECIFICATION · DRAFT FOR DISCUSSION

Concept Fidelity Score

working name — CFS · v0.1 · nothing here is built yet

A training-free, white-box metric for prompt fidelity in text-to-image diffusion transformers. It scores one generated image from the model's own internals — SAE features on the residual stream — with no human data used anywhere in its construction. Human judgments are used once, held out, to test it. This document fixes what the metric is, what the paper claims, and what result would kill each claim — before anything is built.

Measuresprompt fidelity, per concept
Inputsprompt + one hooked generation
Human dataevaluation only, never fitting
ModelsSD3 · PixArt-α · FLUX
§1

What it is, and what it isn't

Getting the scope wrong is the most common way a metric paper gets rejected. These two lists are the paper's first paragraph and its limitations section, written now.

It is

  • A prompt-fidelity metric: does the generation represent what the prompt asked for, concept by concept.
  • Training-free with respect to human data. Only a calibration corpus of the model's own generations is used, for normalization and concept→latent mapping.
  • White-box: for people who own the model — comparing checkpoints, ablating training choices, evaluating during development.
  • Single-pass: one hooked generation per image. The generation you were going to run anyway.
  • Decomposable: a per-concept score and a worst-concept score come free with the headline number.

It isn't

  • An aesthetic quality metric. It says nothing about beauty, realism, or artifacts unless a prompt concept is affected.
  • A universal benchmark score. It cannot score closed models or pre-existing images — it needs the model's internals at generation time.
  • A learned reward model. No component is fitted to preferences; if one ever is, this claim is forfeited and the paper changes category.
  • A mechanistic explanation of the model. The causal experiments validate the score; they aren't the score.
§2

Definition

Five steps from a prompt and a hooked generation to one number. Steps 1 and 5 are pure text/arithmetic; 2 is a one-time calibration; 3 and 4 run once per image.

01

Concept units from the prompt

C(p) is the set of concept units in prompt p: noun phrases and attribute–object pairs from a dependency parse, capped at K by salience (TF-IDF against a general corpus) for long-form prompts. Each unit is typed object (physical referent) or global (mood, lighting, weather).

Why typed: spatial coherence is a virtue for "a red bird" and a defect for "fog" — global concepts are supposed to be diffuse. The type gates step 4.
02

Concept → latent mapping, contrastively (one-time, per model)

For each block b ∈ B, each latent j, and each concept c that recurs in the calibration corpus, compute a contrast effect size between generations whose prompts contain c and those that don't. L_c(b) is the top-k latents by that contrast, above a fixed threshold τ.

contrastive selection · replaces argmax
d'_j(c, b) = ( mean_{p ∋ c} z̄_j(p, b) − mean_{p ∌ c} z̄_j(p, b) ) / s_pooled
L_c(b)     = top_k { j : d'_j(c, b) > τ }          # k small, e.g. 3–5
# z̄_j(p, b): mean activation of latent j over image tokens, at block b,
#               averaged over the timesteps in T
Why not argmax: the current pipeline's argmax picks the loudest latent, not the concept-specific one. At t=0.0 it selects the same latent for 94/94 concepts at block 4 and 102/104 at block 8 — a prompt-agnostic feature carrying zero concept information — and the one latent tested causally so far encoded texture, not the prompt. Fallback for rare concepts (no corpus contrast available): counterfactual-prompt contrast — generate with c removed from the prompt, take the latents whose activation drops most. Costs one extra generation per rare concept; used only when needed.
03

Per-concept presence, from one hooked generation

Encode image-token activations at each (b, t) ∈ B × T with that block's SAE. Presence is the activation mass of L_c(b), normalized by the calibration-corpus reference for those latents, clipped to [0, 1].

presence S_c · captures omission
S_c = clip( mean_{(b,t)} mean_{j ∈ L_c(b)} z̄_j(x, b, t) / ref_j(b), 0, 1 )
# ref_j(b): median activation of latent j on calibration generations whose prompt contains c
04

Spatial coherence and binding (gated by concept type)

For object concepts only: coherence H_c is the existing concentration measure (1 − normalized spatial variance) of the concept's activation map. For attribute–object pairs (a, o): binding B_{a,o} is the normalized overlap of the attribute's and the object's maps. Both in [0, 1]. Neither is computed for global concepts.

coherence H_c and binding B_{a,o}
M_c(x)   = mean_{(b,t)} mean_{j ∈ L_c(b)} z_j(x, b, t)        # per-token map, reshaped to the patch grid
H_c      = concentration( M_c(x) )                          # objects only
B_{a,o}  = < M̂_a(x), M̂_o(x) >                             # cosine of L1-normalized maps; pairs only
05

Combination — fixed, no fitting

Per concept, the geometric mean of whichever components are defined: presence is a gate (a missing concept scores near zero no matter how coherent its map is), which is what "fidelity" should mean. Across concepts, the arithmetic mean is the headline; the minimum is reported alongside as the worst-concept score.

CFS(p, x)
f_c        = geomean( S_c, H_c[if object], B_{c,·}[if paired] )
CFS(p, x)  = mean_{c ∈ C(p)} f_c                   # headline
CFS_min    = min_{c ∈ C(p)}  f_c                   # worst concept; omission / binding detector
Deliberately not in the score: seed-consistency (needs multiple generations — reported as a model-level statistic, not per image) and causal ablation effect size (validation only, §3 C4). Keeping both out is what keeps the metric single-pass.
§3

Claims, and what each one costs

Every experiment in the paper must map to a row here. headline claims carry the paper; gate claims must pass before the headline experiments are worth running; support claims are expected by reviewers but don't decide acceptance.

#claimexperimentpass criterionstatus
C1 headline CFS correlates with human prompt-fidelity judgments at least as well as the best black-box metric on standard prompt sets. Pairwise human study, ≥3 raters, ≥500 pairs per set: DrawBench, PartiPrompts, T2I-CompBench prompts, generated by all three models. Baselines: CLIPScore, VQAScore, ImageReward, PickScore, HPSv2. Non-inferiority: pairwise accuracy / Spearman within bootstrap CI of the best baseline, on the held-out test split. not started
C2 headline On long-form prompts (>77 tokens: poems, VIST stories), CFS beats CLIPScore and matches or beats VQAScore. Same study design on the 600-prompt literary set. Rating task narrowed to "captures the main subject of the text?"; inter-rater agreement reported. Correlation difference vs. CLIPScore significant (Steiger / bootstrap) at n≥500; vs. VQAScore non-inferior or better. not started
C3 gate The SAE earns its cost: CFS beats white-box attention-based baselines (DAAM-style attention mass and concentration, per-token attention strength). Same images and human data as C1/C2; attention baselines computed from the same hooked generations. Significantly better on the long-form set, non-inferior elsewhere. Run first on the dev split — before the full human study. not started
C4 gate Selected latents are causally load-bearing: ablating L_c reduces concept presence more than ablating control latents; amplifying increases it. Causal Ablation Protocol, scored with an objective detector on a controlled prompt set (not pixels, not CLIP). N≥150 concept instances, timestep-stratified. Paired Wilcoxon real vs. control, one-sided, p<0.01, with median effect size reported per (block, timestep). pilot N=1 passed
C5 support CFS_min detects omission and binding errors better than black-box metrics at matched thresholds. Controlled prompt set (objects, attributes, counts, relations) with detector ground truth. AUROC per failure type. AUROC improvement over VQAScore significant by bootstrap. not started
C6 support Robust to the SAE: scores stable under SAE retraining and hyperparameter changes. Retrain SAEs with 3 seeds × 2 dictionary sizes; recompute CFS on the test images. Cross-SAE score correlation > 0.9; human correlation unchanged within CI. not started
C7 support Sanity: CFS decreases monotonically under controlled degradation. Counterfactual prompts (remove concepts one at a time); progressive latent-space noise. No human data. Monotone in ≥90% of trajectories; CFS_min drops on the removed concept specifically. not started
C8 support Cost: single-pass, with a one-time calibration. Wall-clock and memory overhead vs. plain generation; calibration cost per model. Per-image overhead < 15% of generation time; calibration reported honestly, whatever it is. not started
§4

Decisions fixed before any human data is seen

Because human judgments may be used only to evaluate, every design choice below is either fixed now from mechanistic evidence, or chosen on a ~100-item dev split that never touches the final result. The test split stays sealed until the C1/C2 tables are produced once.

  • Blocks B: {8, 12, 16, 20} for SD3 and PixArt; FLUX equivalents once its benchmark run exists. Block 4 is dropped — its features are prompt-agnostic across timesteps in the data so far.
  • Timesteps T: mid-to-late trajectory, {0.5, 0.75, 1.0}. t=0.0 is excluded on the collapse evidence in §2 step 02; this is a mechanistic decision, not a tuned one.
  • Latents per concept k: 3, with τ set to d' > 1.0. Alternatives {3, 5} × {0.8, 1.0, 1.5} may be compared on the dev split only.
  • Concept cap K: 8 for long-form prompts; all units for short prompts.
  • Combination: geometric mean within concept, arithmetic mean across — fixed. No weights, learned or hand-set.
  • Calibration corpus: the 4,200-prompt SAE training set's generations. Disjoint from every human-rated prompt by construction.
  • Splits: dev = 100 prompts per set; test = the rest. Assignment by hash of the prompt, written down before generation.
§5

Kill criteria

Written now so that a bad result later is a decision, not a negotiation.

C3 fails on the dev split

Attention-based baselines match CFS within CI. The SAE is not earning its cost. Stop before the human study. Either the concept mapping is still wrong (re-check C4), or the paper is an attention-metric paper and should say so.

C4 fails at scale

Selected latents are no more causal than controls. The concept→latent mapping is broken; nothing downstream measures concepts. Fix step 02 before generating anything for humans to rate.

Inter-rater agreement on long-form prompts is below α = 0.4

The ground truth is too noisy to separate any two metrics. C2 cannot be a headline. Fall back to C1 on standard prompt sets; keep the literary set as a qualitative section.

C1 fails: CFS is worse than the best black-box baseline on standard prompts

A white-box metric that loses to a black-box one on the common case does not get accepted as a metric, regardless of C2. Reframe as a diagnostic tool paper or stop.

§6

What changes from the current pipeline

The infrastructure stays — SAEs, extractors, the patcher, the resumable runners. The definitions change.

argmax latent per (prompt, block, timestep)→contrastive latent set per concept, calibrated once per model
one "concept" = the whole prompt→parsed concept units, typed object / global, capped at K
timesteps {0.0, 0.5, 1.0}→{0.5, 0.75, 1.0}; t=0.0 dropped on collapse evidence
centroid alignment across seeds as a quality score→model-level statistic, reported but not in CFS
concentration for every row→coherence for object concepts only; binding added for attribute–object pairs
no notion of a missing concept→presence S_c gates the score; CFS_min exposes omission
ablation as a proposed sub-metric→ablation as one-time causal validation (C4), keeping the metric single-pass
human ratings to learn combination weights→no weights; human ratings sealed for evaluation only
§7

Order of work

Cheapest, most decisive tests first. The human study is last because it's the most expensive and everything before it can still change what gets rated.

  1. Contrastive mapping (step 02) on the existing SD3 and PixArt calibration generations. No new generation needed for common concepts.
  2. C4 at scale — the ablation protocol, timestep-stratified, detector-scored on a controlled prompt set. Confirms the mapping is causal before anything is built on it.
  3. Implement CFS single-pass (steps 01, 03–05) and C7 sanity checks. No humans yet.
  4. C3 on the dev split — attention baselines vs. CFS on 100 rated pairs. The kill decision lives here.
  5. Generate the standard prompt sets with all three models; freeze the dev/test split.
  6. Human study (C1, C2), then C5, C6, C8. Test split opened once.
