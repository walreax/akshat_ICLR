§1

Picking a real row to test

smoke_test_ablation.py doesn't invent a test case — it reads pixart_benchmark_full/concept_metrics.csv (the live output of the benchmark run already in progress), filters to rows with concentration > 0.6 so the picked latent is a reasonably well-localized concept rather than noise, and takes the single highest-concentration row:

The control latent (3155) is a second index drawn at random from the same SAE's 4096-wide dictionary, re-rolled once to guarantee it isn't 616 itself. It never argmax-fired for any concept at this (block, step) in the benchmark data — it's genuinely an unrelated direction, not a cherry-picked dead one.

§2

Four generations, one seed

Baseline, ablate, amplify, and control-ablate each get a fresh torch.Generator re-seeded to 42 — a generator is consumed as it's used, so reusing one object across four calls would silently give the later ones different noise. SAEFeaturePatcher (built earlier this session — see the Causal Ablation Protocol) is attached only for the three patched runs, and only fires at step_index=0 on transformer_blocks.12; everywhere else the forward pass is untouched.

smoke_test_ablation.py · the actual generation loop
def gen(mode: str, patch_latent=None):
    generator = torch.Generator(device="cpu").manual_seed(seed)
    patcher = None
    if patch_latent is not None:
        patcher = SAEFeaturePatcher(
            sae, patch_latent, block, target_step=step_index,
            mode="ablate" if mode != "amplify" else "amplify",
            factor=3.0, do_cfg=True,
        )
    result = extractor.extract(prompt, generator=generator, patcher=patcher)
    if patcher is not None:
        assert patcher.applied  # the hook really fired, not a silent no-op
    return result["image"]

The assert patcher.applied matters more than it looks: it's the guard against the single most likely failure mode of this whole approach — a block_name or target_step typo that makes the hook attach but never actually match, silently producing four identical images that would look like a "successful" but meaningless test.

§3

Scoring: a proxy, not the real metric yet

The numbers under each image above are mean absolute pixel difference against baseline — not the LPIPS-based specificity score the full protocol calls for. LPIPS isn't wired into this environment yet; raw pixel difference was enough to answer the one question this smoke test needed to answer (does the patch causally move the image at all, and by how much relative to a control), without blocking on an extra dependency install first.

local is the mean difference inside a circular mask centered on the row's own (centroid_x, centroid_y); global is the mean difference over the whole frame. Both are on the raw 0–255 pixel scale, which is why they're directly comparable across rows in the table below.

§4

What the numbers and the images actually say

01

The real/control gap is the headline result, and it's large

Ablating or amplifying latent 616 moved the image by 46–67 (mean abs pixel diff); doing the identical procedure on latent 3155 moved it by 1.3–2.0. That's a 25–35× gap on a single sample — exactly the signature §4 of the protocol predicted for a latent that's a real causal handle on the model, versus one that isn't.

02

This latent encodes texture, not an object

Look at the ablated/amplified panels: a periodic vertical-banding pattern appears and strengthens with the intervention, while the basketball-team composition holds. Latent 616 at block 12 isn't "the concept of a team" in any nameable sense — it looks like a fine-grained texture/moiré channel. That's not a failure of the test; it's exactly the kind of thing causal intervention reveals that a spatial-correlation argmax can't: what a latent actually does, not just where it lines up.

03

The local/global ratio wasn't informative here — and that's diagnostic too

All three ratios land in a narrow 1.2–1.5 band, real latents included, because this row's step_index is 0: the very first denoising step, where the model is still laying down coarse global structure. An intervention there cascades through every later step and changes the whole image, not a masked region — so global Δ grows right alongside local Δ, and the ratio stops being a useful specificity signal. Magnitude (finding 01) still cuts through cleanly; specificity should be expected to work better at late-timestep rows, where denoising is refining local detail rather than composing structure.

Design implication for the full study: run_ablation.py's candidate sampling should stratify across timestep_fraction — not just take the highest-concentration rows regardless of timestep, which today would skew toward early, globally-cascading steps like this one and under-test the late-step, plausibly more spatially-specific cases the local/global scorer is actually designed for.
§5

What this does — and doesn't — prove yet

This confirms the mechanism: SAEFeaturePatcher attaches, fires at exactly the right (block, step), and produces a real, large, latent-specific causal effect. It is N=1 — one row, one model, one timestep. None of the statistical machinery in §5 of the protocol (paired Wilcoxon test, effect size across hundreds of candidates) has run yet, because it can't: that needs the real scorer and the orchestration loop, neither of which exist yet.
